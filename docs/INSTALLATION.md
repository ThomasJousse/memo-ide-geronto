# Installer Mémo IDE Géronto

## Android (application)

1. Sur le téléphone, ouvrir **https://github.com/ThomasJousse/memo-ide-geronto/releases/latest**.
2. Dans « Assets », toucher le fichier `memo-ide-geronto-vX.Y.Z.apk` pour le télécharger.
3. Ouvrir le fichier téléchargé (notification de téléchargement ou application *Fichiers*).
4. Android demande d'autoriser l'installation depuis cette source (Chrome ou Fichiers) : accepter, une seule fois.
5. Toucher **Installer**. Play Protect peut afficher un avertissement (application hors Play Store) : choisir « Installer quand même ».

### Mettre à jour

Quand une nouvelle version existe, un bandeau apparaît sur l'accueil de l'application. Télécharger le nouvel `.apk` et l'ouvrir : il remplace l'ancien sans perdre les favoris ni l'annuaire.

## iPhone, ordinateur (version web)

1. Ouvrir **https://thomasjousse.github.io/memo-ide-geronto/**.
2. iPhone (Safari) : **Partager → Sur l'écran d'accueil**. Android (Chrome) ou ordinateur : menu → **Installer l'application**.
3. Après une première ouverture avec réseau, elle fonctionne hors ligne.

## Sauvegarder l'annuaire

L'annuaire local reste sur l'appareil. Avant de changer de téléphone : Repères → Annuaire local → « Copier l'annuaire », coller le texte dans une note ou un mail à soi-même, puis « Restaurer depuis une copie » sur le nouvel appareil.

## Problèmes fréquents

- « Application non installée » : désinstaller une ancienne version qui viendrait d'une autre source (APK de test), puis réinstaller.
- Le bandeau de mise à jour n'apparaît pas : il nécessite une connexion au lancement ; vérifier manuellement la page des versions.
