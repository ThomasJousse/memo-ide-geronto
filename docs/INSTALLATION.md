# Installer Mémo IDE Géronto sur Android

1. Sur le téléphone, ouvrir la page des versions du projet sur GitHub (onglet **Releases**) et télécharger le fichier `memo-ide-geronto-vX.Y.Z.apk` de la dernière version.
2. Ouvrir le fichier téléchargé (notification de téléchargement ou application *Fichiers*).
3. Android demande d'autoriser l'installation depuis cette source (Chrome ou Fichiers) : accepter, une seule fois.
4. Appuyer sur **Installer**. L'icône apparaît dans la liste des applications.

## Mettre à jour

Télécharger le nouveau `.apk` et l'ouvrir : il remplace l'ancienne version sans rien perdre. Toutes les versions sont signées avec la même clé, sinon Android refuserait la mise à jour.

## Version web (iPhone, PC)

La même application est publiée sur GitHub Pages. Sur iPhone : ouvrir l'adresse dans Safari, puis **Partager → Sur l'écran d'accueil**. Elle fonctionne ensuite hors ligne.

## Problèmes fréquents

- « Application non installée » : désinstaller l'ancienne version si elle venait d'une autre source (par exemple un APK de test non signé), puis réinstaller.
- Play Protect affiche un avertissement : normal pour une application hors Play Store ; choisir « Installer quand même ».
