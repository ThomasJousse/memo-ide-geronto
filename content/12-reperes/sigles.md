|---|---|

| ASG | Assistant de soins en gérontologie |

| AOD / AVK | Anticoagulant oral direct / antivitamine K |
| CCAS | Centre communal d'action sociale |
| CLIC | Centre local d'information et de coordination |
| CMRR | Centre mémoire de ressources et de recherche |
| CNO | Complément nutritionnel oral |
| CPTS | Communauté professionnelle territoriale de santé |
| DAC | Dispositif d'appui à la coordination |
| DLU | Dossier de liaison d'urgence |
| EGS | Évaluation gériatrique standardisée |
| EHPAD | Établissement d'hébergement pour personnes âgées dépendantes |
| EMG | Équipe mobile de gériatrie |
| EMSP | Équipe mobile de soins palliatifs |
| ESA | Équipe spécialisée Alzheimer |
| FLS | Filière fracture (Fracture Liaison Service) |
| GMP / PMP | GIR moyen pondéré / Pathos moyen pondéré (EHPAD) |
| HAD | Hospitalisation à domicile |
| HDJ | Hôpital de jour |
| IDEC / IDEL | Infirmière de coordination / infirmière libérale |
| LATA | Limitation et arrêt des thérapeutiques actives |
| MDPH | Maison départementale des personnes handicapées |
| MPI | Médicament potentiellement inapproprié |
| PASA | Pôle d'activités et de soins adaptés |
| PPS | Plan personnalisé de santé |
| SAD | Service autonomie à domicile (ex-SAAD, SSIAD, SPASAD) |
| SCPD | Symptômes comportementaux et psychologiques de la démence |
| SMR | Soins médicaux et de réadaptation (ex-SSR) |
| SSIAD | Service de soins infirmiers à domicile |
| TNC | Trouble neurocognitif |
| UCC | Unité cognitivo-comportementale |
| UHR | Unité d'hébergement renforcée |
| USLD | Unité de soins de longue durée |
