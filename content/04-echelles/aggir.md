La grille AGGIR (Autonomie Gérontologie Groupes Iso-Ressources) est l'outil réglementaire d'évaluation de la dépendance. Elle est remplie par l'équipe médico-sociale du département (APA à domicile) ou le médecin coordonnateur (EHPAD), mais l'infirmière d'EMG la cote très souvent pour orienter et argumenter une demande.

## Les variables

| Variables discriminantes (calcul du GIR) | Variables illustratives (dossier, plan d'aide) |
|---|---|
| Cohérence · Orientation · Toilette · Habillage · Alimentation · Élimination · Transferts · Déplacements intérieurs · Déplacements extérieurs · Alerter | Gestion · Cuisine · Ménage · Transports · Achats · Suivi du traitement · Activités de temps libre |

Dans l'algorithme, les déplacements extérieurs et l'alerte ont un poids quasi nul : le GIR repose sur les **huit premières variables**.

## Coder A, B ou C

On code ce que la personne **fait réellement seule**, en observant et en interrogeant l'entourage, jamais ce qu'elle « pourrait » faire.

| Modalité | Définition |
|---|---|
| **A** | Fait seule, **spontanément, totalement, habituellement et correctement** |
| **B** | Fait partiellement, ou pas habituellement, ou pas correctement, ou seulement sur stimulation |
| **C** | Ne fait pas, ou ne remplit aucun des quatre adverbes |

Six variables se codent par sous-variables puis se synthétisent (guide CNAMTS 2008) :

| Variable | Sous-variables | Synthèse |
|---|---|---|
| Cohérence | communication, comportement | AA = A ; un seul C = C ; sinon B |
| Orientation | temps, espace | AA = A ; un seul C = C ; sinon B |
| Toilette | haut, bas | AA = A ; CC = C ; sinon B |
| Habillage | haut, moyen, bas | AAA = A ; CCC = C ; sinon B |
| Alimentation | se servir, manger | AA = A ; CC, BC, CB = C ; sinon B |
| Élimination | urinaire, fécale | AA = A ; un seul C = C ; sinon B |

Ouvrir la [grille interactive](#e-scale-aggir) : elle applique l'algorithme officiel (8 groupes de pondération, 13 rangs) et affiche le GIR.

## Lire le GIR

| GIR | Profil | Droits |
|---|---|---|
| 1 | Confinée au lit ou au fauteuil, fonctions mentales gravement altérées, ou fin de vie | APA |
| 2 | Confinée au lit ou au fauteuil, fonctions mentales partiellement conservées ; ou déambulation avec fonctions mentales altérées | APA |
| 3 | Fonctions mentales conservées, autonomie locomotrice partielle, aide corporelle plusieurs fois par jour | APA |
| 4 | Aide aux transferts, ou aide pour la toilette, l'habillage et les repas | APA |
| 5 | Aide ponctuelle (toilette, repas, ménage) | Aide ménagère (caisse de retraite), pas d'APA |
| 6 | Autonome pour les actes essentiels | — |

> [!repere]
> Le GIR est une photographie : il change après une hospitalisation, une chute ou une décompensation. Pour une demande d'APA, joindre le certificat médical et décrire concrètement les aides nécessaires (plan d'aide), le GIR seul ne suffit pas.

> [!attention]
> Ne pas confondre dépendance et incapacité : une personne qui refuse de se laver (B ou C en toilette) sans trouble moteur relève d'une évaluation de la cohérence et d'une approche relationnelle, pas seulement d'une aide humaine.
