| Point | Détail |
|---|---|
| **Indications** | Douleur neuropathique (post-zostérienne, diabétique), épilepsie ; prégabaline : anxiété généralisée |
| **Prégabaline chez l'âgé** | Débuter 25 à 75 mg/j ; clairance 30 – 60 : max 300 mg/j ; 15 – 30 : max 150 mg/j ; < 15 : max 75 mg/j |
| **Gabapentine chez l'âgé** | Débuter 100 à 300 mg le soir ; doses réduites si clairance < 80 |
| **Effets indésirables** | **Vertiges, somnolence, chutes**, confusion, œdèmes, prise de poids, vision floue ; dépression respiratoire si associés aux opioïdes |
| **Arrêt** | Progressif sur au moins une semaine |
| **Prescription** | Prégabaline sur ordonnance sécurisée (mésusage) |
| **Formes** | Gélules ouvrables, solution buvable (gabapentine) |
