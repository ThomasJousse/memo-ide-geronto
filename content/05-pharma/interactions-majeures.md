| Association | Risque |
|---|---|
| AVK + antibiotiques, amiodarone, fluconazole, miconazole (même gel buccal) | **Hausse de l'INR**, saignement |
| Anticoagulant + antiagrégant, AINS, ISRS | Saignement |
| IEC ou ARA2 + spironolactone, triméthoprime (Bactrim), potassium | **Hyperkaliémie** |
| IEC ou ARA2 + diurétique + AINS (« triple whammy ») | **Insuffisance rénale aiguë** |
| Digoxine + amiodarone, vérapamil, clarithromycine ; hypokaliémie | Toxicité digitalique |
| Colchicine + clarithromycine, érythromycine ; insuffisance rénale | Toxicité grave de la colchicine |
| Statines (simvastatine, atorvastatine) + clarithromycine, amiodarone | Rhabdomyolyse |
| Tramadol, ISRS, IRSNA, linézolide, triptans entre eux | Syndrome sérotoninergique |
| Opioïdes + benzodiazépines, gabapentinoïdes | Dépression respiratoire, sédation |
| Plusieurs anticholinergiques | Confusion, rétention |
| Plusieurs médicaments allongeant le QT | Torsade de pointes |
| Lévothyroxine + calcium, fer, IPP | Baisse d'absorption (espacer de 2 à 4 h) |
| Clopidogrel + oméprazole, ésoméprazole | Moindre efficacité du clopidogrel |
| Allopurinol + azathioprine | Toxicité hématologique |
| Métformine + produit de contraste iodé (si IR) | Acidose lactique |

> [!repere]
> Avant toute **antibiothérapie** chez un patient sous AVK : prévoir un contrôle de l'INR dans les 3 à 4 jours.
